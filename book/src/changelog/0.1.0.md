# 0.1.0 (2026-11-23)

First regular release. Covers 100 % of the measured official bot API (see [Discord API Coverage](../coverage.md): endpoints, gateway events, opcodes, close codes, enum values, object fields and flags against `discord-api-docs@9b737ec51ee8`).

From here on normal SemVer for `0.x`: a minor release may break the API, a patch release never does.

## Highlights

- **Metrics getters:** `ShardStatus::counters` (`ShardCounters`) and `Client::metrics()` (`ClientMetrics`).
- **Configurable decompressed-message cap:** `max_message_bytes` on `ShardBuilder` and `ShardManagerBuilder` (default `16 MiB`).
- **Faster parsing and caching:** `INTERACTION_CREATE` parses `data` in one pass; `GUILD_CREATE` uses one lock per map with reserved capacity. See [Performance & Benchmarks](../performance.md).
- **`InteractionClient`:** `client.interaction(app_id)` for application-scoped endpoints without repeating the ID.
- **Builders for every component**, including Components V2 (`Container`, `Section`, `TextDisplay`, `Thumbnail`, `MediaGallery`, `FileComponent`, `Separator`) with automatic `IS_COMPONENTS_V2` flag handling.
- **`ctx.button_clicks(message, timeout)`** and **live resharding** in `Bot` (`Bot::reshard_interval`).
- **Social SDK REST & models (100 % coverage):** lobbies, application identity profiles, and webhook events (`LOBBY_MESSAGE_*`, `GAME_DIRECT_MESSAGE_*`).
- **Ergonomics:** embed builder with local limits, CDN URLs, `Mentionable` & `parse_mentions`, timestamp markdown, `Standby` / `ctx.wait_for_*`, permission calculator, `default_allowed_mentions`, `parse_webhook_url`.
- **All 82 gateway receive events typed** with matching `EventTypeFlags`.

For the full pre-release beta history (`0.1.0-beta.1` – `0.1.0-beta.4`), see [`CHANGELOG.md`](https://github.com/lejylabs/cordex/blob/master/CHANGELOG.md).
