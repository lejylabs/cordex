# 0.2.0 (2026-11-26)

- **Background Tasks / Scheduler & First-Class i18n:**
  - Added lifecycle-bound `Bot::every`, `Bot::every_immediate`, and `Bot::background` (and on `BotModule`) with `ShutdownToken`, `SchedulerHandle`, `MissedTickBehavior::Skip`, panic/error isolation, and graceful shutdown.
  - Added `Locale` enum in `cordex-model`, `locale()` / `guild_locale()` / `effective_locale(default)` on all interaction contexts, `.name_localized` / `.description_localized` & bulk `.name_localizations` / `.description_localizations` on `Command` / `CommandOption`, and `book/src/i18n.md`.
- **Offline Testing-Harness & Gateway-Replay (`cordex-test` + `cordex-gateway/record`):**
  - Added `cordex-test` with `TestBot` (wraps any `Bot` without code changes), in-memory `MockHttp` recorder & error injection, cache pre-seed helpers (`seed_guild`, `seed_channel`, `seed_user`, `seed_member`), interaction/event builders (`slash`, `click_button`, `submit_modal`, `trigger_autocomplete`, `send_message`), assertions (`assert_replied`, `assert_ephemeral`, `assert_deferred`, `assert_modal`, `assert_autocomplete_choices`, `assert_sent_message`), and `tokio::time::pause()` / `advance()` support.
  - Added opt-in `record` feature on `cordex-gateway` (`TrafficRecorder`, `RecordedFrame`, consistent 1:1 `Anonymizer`) and `TestBot::replay_jsonl` / `replay_jsonl_str`.
- **Discord Everyday Toolkit, Middleware & Components V2:**
  - Added `Bot::around_command`, `BotModule::around_command`, and `Next::run(ctx)` for composable command middleware.
  - Added `SyncReport`, `diff_commands`, `dev_guild_id_from_env`, and `Bot::sync_dev_guild_from_env()` (`DISCORD_DEV_GUILD_ID`).
  - Added stateless HMAC-SHA256 signed `custom_id` payloads (`CustomIdSigner`, `SignedCustomId`, `CustomIdError`) within Discord's 100-char limit.
  - Added fluent Components V2 `LayoutBuilder` with local limit validation and automatic `IS_COMPONENTS_V2`.
  - Added codeblock-aware `split_message` / `split_message_2000` / `split_message_4096`, `escape_markdown`, `escape_mentions`, and `permission_calc::highest_role_position`.
- **Production Resilience, Cache Eviction & Observability:**
  - Added `SessionStore` trait and atomic `FileSessionStore` in `cordex-gateway` for zero-downtime `RESUME` persistence.
  - Added priority-aware global rate limiting (`RequestPriority::{Critical, Normal, Background}` with fair-scheduling aging) in `cordex-http`.
  - Added bounded cache eviction & write-through in `cordex-cache` (`max_messages_per_channel`, `max_users`, `member_ttl`, `write_through`) and REST-fallback write-through in `Context`.
  - Added `Context::health_snapshot() -> HealthSnapshot` (`ShardHealth`, `CacheHealth`, `is_ready()`, `to_json()`).
- **Performance, Memory-Footprint & Bug-Hardening:**
  - Hardened auto-defer state machine (`ResponseState`), resumable WebSocket close codes (`4000`), `Standby` cancellation `Drop` guards, cooldown map eviction, HTTP rate-limit bucket cleanup, `FxHash` for snowflake cache maps, decompress buffer `shrink_to`, and `size_of` regression tests.
