# 0.1.1 (2026-11-23)

- **`cordex-cache`: per-resource `CachePolicy` (`Off`, `Lazy`, `Eager`).**
  - `CacheConfig::lazy(...)` and `CacheConfig::with_policy(..., CachePolicy::Lazy)` skip bulk dumps (`GUILD_CREATE`, `GUILD_MEMBERS_CHUNK`, `THREAD_LIST_SYNC`, `SOUNDBOARD_SOUNDS`) and cache entries only when seen in live events (messages, interactions, member/voice/guild/channel/role updates, etc.).
  - Purely lazy configs omit `GUILD_CREATE` from `wanted_events()`.
  - `GuildMemberUpdate::to_member()` added in `cordex-model`.
