# Localization (i18n)

Discord natively supports localized command names, descriptions, option names, and per-user/per-guild locales on every interaction. `cordex` exposes these directly without pulling in any external i18n framework.

## Localized Command Definitions

Use `.name_localized(...)` / `.description_localized(...)` (or bulk `.name_localizations(...)` / `.description_localizations(...)`) on `Command`, `CommandOption`, and `Choice`:

```rust
use cordex::prelude::*;

let profile = Command::slash("profile", "Show a user profile")
    .name_localized(Locale::De, "profil")
    .description_localized(Locale::De, "Zeigt ein Nutzerprofil")
    .name_localized(Locale::Fr, "profil")
    .description_localized(Locale::Fr, "Affiche un profil utilisateur");
```

## Reading the User or Guild Locale

Every interaction context (`CommandContext`, `ComponentContext`, `ModalContext`, `AutocompleteContext`) provides:

- `ctx.locale() -> Option<&str>` — the invoking user's Discord client locale (e.g. `"de"`, `"en-US"`).
- `ctx.guild_locale() -> Option<&str>` — the server's preferred locale (when invoked in a guild).
- `ctx.effective_locale(default) -> &str` — falls back from `locale()` → `guild_locale()` → `default`.

## Zero-Dependency `Translations` Pattern with `Bot::data`

Store your own translation table in `Bot::data(...)` and expose a tiny extension trait:

```rust
use std::collections::HashMap;
use cordex::prelude::*;

struct Translations(HashMap<(&'static str, &'static str), &'static str>);

impl Translations {
    fn get(&self, locale: &str, key: &'static str) -> &'static str {
        self.0
            .get(&(locale, key))
            .or_else(|| self.0.get(&("en-US", key)))
            .copied()
            .unwrap_or(key)
    }
}

trait Translate {
    fn t(&self, key: &'static str) -> &'static str;
}

impl Translate for CommandContext {
    fn t(&self, key: &'static str) -> &'static str {
        let locale = self.effective_locale("en-US");
        self.data::<Translations>()
            .map_or(key, |tr| tr.get(locale, key))
    }
}
```
