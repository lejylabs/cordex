# Security policy

## Supported versions

Only the latest `0.x` release gets security fixes during the beta.

## Reporting a vulnerability

Please do **not** open a public issue. Report it privately through
[GitHub security advisories](https://github.com/lejylabs/cordex/security/advisories/new).
You get an answer within 7 days. Include the affected version, a description
and, if possible, steps to reproduce.

Bot tokens and interaction tokens are secrets: never paste them into reports.
