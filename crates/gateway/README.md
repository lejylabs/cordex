# cordex-gateway

Discord gateway: shards with zlib-stream, heartbeat, resume/reconnect, event filter, backpressure; shard manager and identify queue.

Part of [cordex](https://github.com/lejylabs/cordex), an independent Discord
bot API library for Rust. Most users depend on the facade crate
[`cordex`](https://crates.io/crates/cordex) instead of this one.

Questions or help: [cordex Discord server](https://discord.gg/Xj9nRKyKNV).
